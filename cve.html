为什么 CVE 数量远少于漏洞数量？主机破解的很大一部分成果根本拿不到 CVE：直读芯片、脉冲注入、电压毛刺这类硬件改机不是软件漏洞； PS1、PS2、Xbox 初代等早期平台的缺陷大多早于「消费级设备漏洞普遍编号」的年代；而 Switch、PlayStation 的固件漏洞常由厂商内部修复、 或经漏洞赏金计划私密披露，未申请编号。反过来，主机里复用的通用组件（FreeBSD 网络栈、WebKit、Chakra、NSS、Windows 内核）一旦被利用， 几乎都带着现成的 CVE 编号。

因此本页是「已编号漏洞」的完整索引，而不是「全部漏洞」的索引。没有 CVE 的条目仍完整保留在各机型时间轴中， 其 cve 字段为空是刻意为之——宁可留空，也不虚构编号。
